A console bases Library management system in C++ that practices Object orientated programming, STL(vectors), references, const correctness and exception handling.
##Features: Add a book, Search Book, borrow book, return book, remove book, validate book information,  handle invalid operations using exception handling, Validate menu choices.
##OOPs concepts demonstrated: Objects and classes, Constructors, Encapsulation, STL(vectors and string), references, const correctness, Exception Handling.
##Technologies used: C++, Standard template library, Visual Studio code, Git & Github.
##Project Structure: main.cpp Book.h, Book.cpp, Library.cpp, Library.h README.md.
##How it works: The program presents the user with a menu of operations. Books are stored in a vector<Book> inside the Library class. The Library class is responsible for managing the collection, while the Book class is responsible for the state and behavior of individual books.
##Future Improvements: Persistent storage using file handling, Loading books when the program starts, storing Books when the program exits, Improved user validation, more advanced user interface, separating librarians and users into different class.
